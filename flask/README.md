#   Backend Server
## Requirements
Minimal Python ≥ 3.9

Recommended Python 3.12.3

## Install python libraries
```bash
pip install -r requirement.txt
```
## Endpoints:
* POST /api/register
* POST /api/login
* POST /api/watchlist
* GET /api/watchlist
* GET /api/movies
* GET /api/recommendation
